## 2. 배경 — 왜 문제였나

`TwistCmdCallback`이 주행모드를 **Twist 값만으로 상태 없이(stateless)** 결정하고, 드라이버에 히스테리시스·최소 유지시간이 **전혀 없다**.

- ackermann↔spinning 경계는 오직 `|linear.x| < 1e-6` 단일 임계에 걸림.
- 속도가 0 근처에서 오르내리면(감속 꼬리, 접근 지터) 매 콜백마다 모드가 왕복 전환.
- 실제 모드 전환 1회당 섀시가 조향을 **~0.6초 재구성**하며 그동안 속도 명령을 무시(주석 `ranger_messenger.cpp` 참고) → 주행 중 멈칫거림 누적.

> cona planner(planner_yn)는 유니사이클 `(v, ω)`를 내보내며 최소 회전반경 개념이 없다. 접근/정렬 단계에서 `v=0` 제자리 회전과 주행을 오가므로 이 경계 왕복이 실제로 발생할 수 있는 구간.

## 3. 수정 내용

### 3.1 히스테리시스 (진입/이탈 이중 임계)
```
before: |linear.x| < 1e-6 && |angular.z|>1e-6  → SPINNING, 그 외 → DUAL_ACKERMAN

after (현재 모드 기억):
  현재 SPINNING 아님 : |linear.x| < spin_enter_vx(1e-3) && 회전명령 있음 → SPINNING
  현재 SPINNING      : |linear.x| > spin_leave_vx(3e-2) 또는 회전 멈춤   → DUAL_ACKERMAN
```
→ 0 근처에서 흔들려도 이탈 임계(0.03)를 안 넘으면 spinning 유지 → 경계 채터링 차단.

### 3.2 최소 dwell (시간 잠금)
```
전환 발생 시각 기록(last_mode_switch_time_).
motion_mode 바뀌어도 (now - last_switch) < mode_switch_min_dwell(0.6s) 이면
→ SetMotionMode 호출 안 하고 현재 모드 유지.
commanded_motion_mode_ == 0xFF (최초)는 항상 즉시 전환.
```
→ 실제로 양쪽을 오갈 때도 전환 간격이 재구성 시간(0.6s) 아래로 안 떨어짐.

### 3.3 파라미터 (기본값)
| 파라미터 | 기본값 | 의미 |
|----------|--------|------|
| `mode_switch_min_dwell` | 0.6 s | 전환 후 최소 유지시간 |
| `spin_enter_vx` | 0.001 m/s | 스핀 진입 vx 임계 |
| `spin_leave_vx` | 0.03 m/s | 스핀 이탈 vx 임계 |

정상 주행(속도 유지)·의도적 제자리 회전(`v=0`+회전)은 기존과 동일.

## 4. 검증 (vcan0 + candump, 헤드리스)

이 저장소엔 순수 SW 시뮬레이터가 없음(`simulated_robot` 파라미터는 dead — `LoadParameters`가 안 읽음). 대신 **가상 CAN(vcan0)에 실제 드라이버 노드를 붙이고, 노드가 송신하는 SetMotionMode 프레임(CAN `0x141`, data[0]=모드) 수를 candump로 측정**.

- 모드 값: `00`=DUAL_ACKERMAN, `02`=SPINNING (ugv_sdk `ranger_interface.hpp`).
- 노드는 **모드가 바뀔 때만** 0x141 송신 → 0x141 프레임 수 = 실제 전환 횟수.
- 입력: 경계(vx≈0)를 흔드는 13초 적대적 `/cmd_vel` 파형 (정속주행→접근지터→정지-재출발→순수스핀). 같은 바이너리·같은 파형, 파라미터만 다르게.

| 케이스 | dwell / enter / leave | 전환(0x141) |
|--------|----------------------|-------------|
| 기존 동작 재현 | 0 / 1e-6 / 1e-6 | **53회** |
| 패치 기본값 | 0.6 / 1e-3 / 3e-2 | **9회** |

→ 약 **83% 감소**.

타임라인(패치):
- 접근 지터 구간(vx=0.02, 이탈 임계 0.03 미만): 3초간 전환 0회 (히스테리시스).
- 정지-재출발 구간: 모든 전환 간격이 **≥0.60s**로 바닥 형성 (dwell).

재현 스크립트/파형: 세션 tmp(`pub_seq.py`, `run_case.sh`)에 있음 — 필요 시 이 저장소로 옮길 것.
